How does an autonomous robot work?

An autonomous robot can sense what is nearby and choose an action without a person steering every move. An Arduino is a small programmable board that runs the instructions. An ultrasonic sensor estimates distance by sending out sound and measuring its echo; a servo is a motor that turns to a chosen position. On a two-wheel robot, these parts can help it react to obstacles.

My build

Sensing and moving

I built a two-wheel robot because I wanted it to react to what was around it without being steered for every move. The wheels let it travel, but movement alone would not make it autonomous. It also needed a way to notice nearby objects and a program that could use that information.

For that, I used an ultrasonic sensor to measure distance and an Arduino to run the instructions. A servo is also part of the build. The important step was bringing sensing and movement together, so a distance reading could lead to a decision about what the robot should do next.
