My Projects

Competition robots, robot arms, a walking robot, a drone, and an Arduino-based autonomous robot. Each project has taught me something new about turning an idea into hardware that works.

Project 01

VEX IQ Robotics

VEX IQ is a robotics platform used in competitions where teams build and program a robot to complete tasks on a field. Our robot needed to drive, collect game pieces, and control a fast-spinning wheel called a flywheel.

I worked on it in 2024 and 2025. Once the mechanical parts were in place, I used VEXcode Blocks to control the flywheel with controller and sensor inputs. Then we tested the robot on the field and learned from how it actually behaved.

VEX IQ · VEXcode Blocks · Motors · Sensors

Project 02

SO-101 Robot Arm

A robot arm moves through motor-driven joints, much like a human arm. In my SO-101 setup, the goal is to move one arm by hand and have a second arm copy it.

Before that can work, I need to configure both arms on my Mac. I am checking the connections and motors, working with calibration files, setting up cameras, and then testing the movement step by step.

LeRobot · Python · Camera setup · Motor calibration

Project 03

Open Duck Mini V2

Open Duck Mini V2 is a small two-legged robot designed to balance and walk. Before it can take a step, its computer must communicate with the leg motors and check its body position.

I am working through the wiring, motor communication, motion sensor, joint positions, and controller connection. A safely calibrated walking test is the next milestone, not something I have finished yet.

Raspberry Pi · Python · Linux · Motors · IMU

Project 05

Two-Wheel Autonomous Robot

An autonomous robot uses sensors and code to react without someone steering every move. To do that, a two-wheel robot needs both a way to travel and a way to notice what is nearby.

I built mine with an Arduino, an ultrasonic distance sensor, and a servo. I brought sensing and movement together so the robot could make decisions; I will add its exact obstacle response and code next.
