What is VEX IQ?

VEX IQ uses parts that fit together, motors, sensors, and code to build small robots. In a competition, teams make a robot for a game played on a field. Its wheels and driving motors are called the drivetrain; an intake brings game pieces into the robot; and a flywheel is a fast-spinning part. Code tells these parts when to work.

My build

From code to competition

VEX IQ · VEXcode Blocks · Motors · Sensors

I worked on VEX IQ in 2024 and 2025, learning how mechanical design and code affect what a robot does on the field.

My saved VEXcode project uses controller input and a bumper sensor to control a flywheel, along with a two-motor drivetrain and intake. Team practice and testing helped us improve the robot.

Build notes

  • Two-motor drivetrain and intake for moving around the field and handling game pieces.
  • Flywheel controlled through the controller and bumper-sensor input in my saved VEXcode project.
